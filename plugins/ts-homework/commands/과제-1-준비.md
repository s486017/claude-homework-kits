`ts-homework` 스킬의 **① 준비** 단계를 수행한다.

1. 현재 폴더에 `ts_kit.config.json` 이 있는지 확인한다.
2. 없으면 사용자에게 **이름, 학번, 과제 번호**를 묻는다.
   과제 번호를 모르면 1 로 둔다 — 산출물 이름이 `과제1_...` 로 붙어 다음 과제와 섞이지 않는다.
   이어서 **노트북을 어떻게 받았는지** 묻는다 — 공개 저장소 주소 / 내 PC 의 파일·폴더 /
   Colab 링크 중 하나면 된다. **사용자 본인의 GitHub 계정이나 저장소는 필요 없다.**
   저장소 주소를 준 경우에만 `--repo` 로 넘긴다.
   셋 다 없으면 진행하지 않는다 — 추측해서 채우지 않는다.
3. 가상환경(`.venv`)이 없고 사용자가 쓰고 있지도 않다면, 만들지 먼저 물어본다.
4. `${CLAUDE_PLUGIN_ROOT}/scripts/setup_env.py` 를 인자와 함께 실행한다.
5. 출력에서 **한글 폰트 줄과 이름/학번 경고**를 확인하고, 문제가 있으면 사용자에게 알린다.

사용자가 추가로 준 내용: $ARGUMENTS
