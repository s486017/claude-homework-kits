description: 마크다운 보고서를 Word(.docx)로 변환하고 제출 전 검증한다 (4단계)
---

`ts-homework` 스킬의 **④ 문서화** 단계를 수행한다.

1. `${CLAUDE_PLUGIN_ROOT}/scripts/batch_docx.py` 로 `보고서/*.md` 를 전부 변환한다.
2. `${CLAUDE_PLUGIN_ROOT}/scripts/verify_docx.py --render` 로 검증한다.
3. **문제가 하나라도 나오면 원인을 고치고 다시 변환한다.** 스킬의 "흔한 원인" 표를 참고한다.
   검증 결과를 그냥 보고하고 넘어가지 않는다.
4. 사용자가 처음 쓰는 경우라면, 변환된 문서 **한 개를 먼저 보여 주고 확인받은 뒤** 전체를 돌린다.
5. 끝나면 문서 수, 총 페이지, 그림 수, 링크 상태를 표로 보고하고 저장 위치를 알려 준다.

글꼴·본문 크기·그림 폭·페이지 나눔을 바꾸려면 `ts_kit.config.json` 의 `docx` 항목을 고친 뒤
다시 변환한다.

사용자가 추가로 준 내용: $ARGUMENTS
