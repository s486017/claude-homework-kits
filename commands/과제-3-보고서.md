description: [3/4] 실행 결과를 읽고 노트북별 마크다운 보고서를 작성한다
---

`ts-homework` 스킬의 **③ 보고서** 단계를 수행한다. 스킬의 문서 구조와 작성 원칙을 그대로 따른다.

1. `실행결과/*/summary.md` 를 읽는다. **출력과 그림을 실제로 확인한다** — 결과를 지어내지 않는다.
2. 문체를 사용자에게 먼저 확인한다 (예: "~함" 체, "~다" 체, 존댓말).
3. **먼저 한 개만 써서 사용자에게 확인받는다.** 승인 후 나머지를 같은 틀로 쓴다.
4. 각 문서는 `보고서/과제<번호>_<노트북명>.md` 로 저장한다 (번호는 `ts_kit.config.json` 의
   `assignment.number`). 그림은 `../실행결과/<노트북명>/cellNN_figK.png` 상대경로로 건다 —
   **실행결과 폴더는 과제 번호를 붙이지 않는다.** 같은 노트북 실행 결과를 다음 과제에서도 쓰기 때문이다.
5. 절마다 `<a id="sN"></a>` 앵커를 넣고 상단 목차에서 `[제목](#sN)` 으로 연결한다.
6. 마지막에 `보고서/과제<번호>_00_목차.md` 를 만든다 — 맨 위에 **"과제 N — 제목"**, 이름·학번,
   과제 개요, 각 문서 링크, 오류·수정 종합표.
7. 끝나면 문서 수, 절 수, 첨부 그림 수를 보고한다.

문서가 많으면 나눠서 병렬로 쓰되, 3번의 본보기 문서를 기준으로 문체와 구조를 맞춘다.
