# 과제 자동화 키트 모음 (homework-kits)

대학원 과제를 Claude 와 함께 처리하는 **Claude Code 플러그인 모음**입니다.
손으로 반복하던 일 — 환경 세팅, 실행, 결과 정리, 제출 문서 만들기 — 을 도구로 굳혀 둔 것입니다.

## 설치

Claude Code 에서 한 번만 등록하면, 이 저장소의 키트를 전부 골라 쓸 수 있습니다.

```
/plugin marketplace add s486017/claude-homework-kits
```

그다음 필요한 키트를 설치합니다.

```
/plugin install ts-homework@homework-kits
```

## 들어 있는 키트

| 키트 | 무엇을 하나 | 문서 |
|---|---|---|
| **ts-homework** | 주피터 노트북 과제 — 노트북 내려받기·실행, 오류 수정 기록, 실행 결과로 보고서 작성, Word(.docx) 변환과 제출 전 검증 | [자세히](plugins/ts-homework/README.md) |

설치 후에는 명령을 외울 필요가 없습니다. "노트북 과제 좀 도와줘" 라고 하면 알맞은 키트가 잡힙니다.

### 필요한 키트 하나만 받아도 됩니다

두 명령의 역할이 다릅니다.

| 명령 | 하는 일 |
|---|---|
| `/plugin marketplace add ...` | **목록만 등록합니다.** 설치가 아닙니다 — 어떤 키트가 있는지 알려 주는 것뿐입니다 |
| `/plugin install <키트>@homework-kits` | **고른 키트 하나만** 설치하고 켭니다 |

노트북 과제 키트만 필요하면 `ts-homework` 하나만 설치하면 됩니다. 나중에 이 저장소에 키트가
더 추가돼도 **자동으로 따라오지 않습니다.** 필요해지면 그때 골라서 설치하면 됩니다.

```
/plugin list                       # 설치된 것 보기
/plugin uninstall ts-homework      # 필요 없어지면 제거
```

## 새 키트를 추가하려면

키트 하나가 폴더 하나입니다.

```
plugins/<키트이름>/
├─ .claude-plugin/plugin.json   # 이름·설명·버전
├─ skills/<이름>/SKILL.md        # Claude 가 읽는 작업 절차서
├─ commands/*.md                # 슬래시 명령 (선택)
├─ scripts/*.py                 # 실제로 일하는 스크립트 (선택)
└─ README.md                    # 사람이 읽는 설명
```

폴더를 만든 뒤 루트의 `.claude-plugin/marketplace.json` 의 `plugins` 배열에 한 줄 추가하면 끝입니다.

```json
{ "name": "<키트이름>", "source": "./plugins/<키트이름>", "description": "..." }
```

만들 때 지킨 것들:

- **경로를 하드코딩하지 않는다** — 사용자의 작업 폴더 기준으로 동작하고, 윈도우·맥·리눅스에서 같이 돈다.
- **개인 정보를 넣지 않는다** — 이름·학번 같은 값은 설정 파일로 빼고, 비어 있으면 사용자에게 묻는다.
- **저작권 자료를 넣지 않는다** — 강의안 PDF 등은 저장소에 올리지 않는다.
- **결과를 검증한다** — 만들어 놓고 끝내지 말고, 제출 전에 무엇이 깨졌는지 스스로 확인하게 한다.
